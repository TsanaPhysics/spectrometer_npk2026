\chapter{การติดตั้งเฟิร์มแวร์และการตั้งค่าซอฟต์แวร์}
\label{chap:ch03}

\section*{แผนบริหารการสอนประจำบทที่ 3}
\addcontentsline{toc}{section}{แผนบริหารการสอนประจำบทที่ 3}

\begin{planbox}{หัวข้อเนื้อหาประจำบท}
\begin{enumerate}[leftmargin=1.5em, itemsep=1pt]
    \item สถาปัตยกรรมเฟิร์มแวร์บนระบบนิเวศ Seeeduino SAMD Core
    \item รายการไลบรารีเฉพาะของ Wio Terminal และการตั้งค่า Smooth Font
    \item ขั้นตอนการคอมไพล์และแฟลชโปรแกรมด้วย Arduino CLI
    \item การกู้คืนระบบผ่านโหมด Bootloader และการติดตั้งไฟล์ไบนารี UF2
\end{enumerate}
\end{planbox}

\begin{planbox}{วัตถุประสงค์เชิงพฤติกรรม}
\begin{enumerate}[leftmargin=1.5em, itemsep=1pt]
    \item ติดตั้งและกำหนดค่าไลบรารีซอฟต์แวร์สำหรับบอร์ด Wio Terminal ได้อย่างถูกต้อง
    \item คอมไพล์และอัปโหลดโปรแกรมผ่านบรรทัดคำสั่ง Arduino CLI ได้อย่างสมบูรณ์
    \item อธิบายขั้นตอนการกู้คืนบอร์ดไมโครคอนโทรลเลอร์กรณีพอร์ตเชื่อมต่อค้างได้อย่างถูกต้อง
\end{enumerate}
\end{planbox}

\begin{planbox}{กิจกรรมการเรียนการสอน}
\begin{enumerate}[leftmargin=1.5em, itemsep=1pt]
    \item การสาธิตการตั้งค่าสภาพแวดล้อมการพัฒนา Arduino CLI และ Board Core
    \item ปฏิบัติการติดตั้งไลบรารีและการปรับแต่งไฟล์ User\_Setup.h
    \item การทดลองคอมไพล์ อัปโหลด และตรวจสอบการใช้หน่วยความจำแฟลชและแรม
\end{enumerate}
\end{planbox}

\begin{planbox}{สื่อการเรียนการสอน}
\begin{enumerate}[leftmargin=1.5em, itemsep=1pt]
    \item เครื่องคอมพิวเตอร์พร้อมระบบปฏิบัติการ macOS หรือ Linux และ Arduino CLI
    \item ซอร์สโค้ดเฟิร์มแวร์ spectrometer\_npk2026.ino และไฟล์เฮดเดอร์โมดูล
    \item สายเคเบิล USB-C คุณภาพสูงสำหรับการส่งผ่านข้อมูลและการจ่ายไฟ
\end{enumerate}
\end{planbox}

\begin{planbox}{การวัดและประเมินผล}
\begin{enumerate}[leftmargin=1.5em, itemsep=1pt]
    \item การประเมินผลสำเร็จของการคอมไพล์โปรแกรมโดยปราศจากข้อผิดพลาด
    \item การทดสอบการบูตเครื่องและการแสดงผลหน้าจอ Dashboard บน Wio Terminal
    \item การตรวจความถูกต้องของการตอบคำถามทบทวนท้ายบทที่ 3
\end{enumerate}
\end{planbox}

\section{สถาปัตยกรรมเฟิร์มแวร์บน ATSAMD51}
เฟิร์มแวร์ของเครื่องสเปกโทรโฟโตมิเตอร์พัฒนาขึ้นบนระบบนิเวศ Arduino โดยปรับแต่งให้ทำงานบนสถาปัตยกรรม ARM Cortex-M4F ของไมโครคอนโทรลเลอร์ Microchip ATSAMD51P19A บนบอร์ด Seeed Studio Wio Terminal พร้อมระบบบริหารจัดการหน่วยความจำและจอแสดงผลที่มีประสิทธิภาพสูง โครงสร้างโค้ดเป็นแบบโมดูลาร์ (Modular Architecture) แยกการคำนวณออกเป็นเอนจินเฉพาะ
\begin{itemize}[leftmargin=1.5em, itemsep=2pt]
    \item \texttt{TinyML\_Model.h} โครงข่ายประสาทเทียม Multi-Layer Perceptron ($6 \to 12 \to 8 \to 3$)
    \item \texttt{Calibration\_Engine.h} การวิเคราะห์การถดถอยเชิงเส้นตรง OLS, $R^2$, LOD, LOQ
    \item \texttt{Spectrum\_Engine.h} การสแกนสเปกตรัมแสงหลายช่วงคลื่นและพล็อตกราฟิก 2D
    \item \texttt{Liquid\_Engine.h} การคำนวณดัชนีหักเห ($n$), ความหนาแน่น ($\rho$), Brix ($^\circ\text{Bx}$) และระดับความขุ่น
\end{itemize}

\section{ไลบรารีที่จำเป็นสำหรับระบบ}
การพัฒนาและคอมไพล์โปรแกรมต้องการไลบรารีมาตรฐานดังต่อไปนี้

\begin{enumerate}[leftmargin=1.5em, itemsep=3pt]
    \item \textbf{Seeed\_Arduino\_LCD} ไลบรารีควบคุมจอแสดงผล TFT LCD ความละเอียด 320x240 พิกเซลผ่านบัส SPI3 เฉพาะตัวของ Wio Terminal
    \item \textbf{Adafruit\_TCS34725} ไลบรารีสื่อสารกับเซนเซอร์วัดค่าสีแบบ I2C ควบคุมเวลาการประมวลผล (Integration Time) และเกนขยายสัญญาณ
    \item \textbf{Adafruit\_NeoPixel} ไลบรารีขับสัญญาณดิจิทัลควบคุมโมดูลหลอดไฟ RGB WS2812B
    \item \textbf{Seeed\_Arduino\_FS และ Seeed\_SD} ไลบรารีจัดการระบบไฟล์และบันทึกข้อมูลลงในการ์ดหน่วยความจำ microSD Card
\end{enumerate}

\begin{academicbox}{การป้องกันปัญหาจอขาวและการตั้งค่าไลบรารี}
    ในการคอมไพล์โปรแกรมสำหรับบอร์ด Wio Terminal จะต้องใช้ไลบรารี \textbf{Seeed\_Arduino\_LCD} ที่ติดตั้งมาพร้อมกับ Core Seeeduino SAMD เท่านั้น โดยห้ามใช้ไลบรารี TFT\_eSPI ทั่วไปของ Bodmer เนื่องจากมีการกำหนดขาสัญญาณ SPI ผิดพลาดและส่งผลให้จอแสดงผลเป็นสีขาวสว่างค้าง
    
    นอกจากนี้ เพื่อให้ระบบสามารถแสดงผลฟอนต์ภาษาไทย THSarabunPSK ได้อย่างคมชัด จะต้องเปิดการทำงานของคุณสมบัติ Smooth Font ในไฟล์ \texttt{User\_Setup.h} ของ Seeed\_Arduino\_LCD โดยเปิดใช้งานบรรทัด
    \begin{center}
        \texttt{\#define SMOOTH\_FONT}
    \end{center}
\end{academicbox}

\section{คำสั่งคอมไพล์และอัปโหลดโปรแกรม}
ผู้ใช้งานสามารถคอมไพล์และอัปโหลดโปรแกรมผ่านโปรแกรม Arduino CLI บนระบบปฏิบัติการ macOS หรือ Linux โดยใช้ชุดคำสั่งดังต่อไปนี้

\begin{center}
\begin{minipage}{0.92\textwidth}
\begin{verbatim}
# Compile sketch for Wio Terminal
arduino-cli compile --fqbn Seeeduino:samd:seeed_wio_terminal \
    firmware/spectrometer_npk2026

# Upload sketch via USB port
arduino-cli upload -p /dev/cu.usbmodem2101 \
    --fqbn Seeeduino:samd:seeed_wio_terminal \
    firmware/spectrometer_npk2026
\end{verbatim}
\end{minipage}
\end{center}

\section{การกู้คืนระบบผ่านโหมด Bootloader}
กรณีที่เกิดปัญหาพอร์ต USB หลุดการเชื่อมต่อหรือไม่ตอบสนอง สามารถแก้ไขได้โดยการเลื่อนสวิตช์เปิดปิดด้านข้างตัวเครื่องลง 2 ครั้งอย่างรวดเร็ว (Double-click Touch Reset) เพื่อเข้าสู่โหมด Bootloader จากนั้นคัดลอกไฟล์ไบนารี \texttt{spectrometer\_npk2026.uf2} ไปวางในไดรฟ์ USB เสมือนที่ปรากฏขึ้น บอร์ดจะทำการรีบูตและรันเฟิร์มแวร์ใหม่โดยอัตโนมัติ

\section*{บทสรุปประจำบทที่ 3}
\addcontentsline{toc}{section}{บทสรุปประจำบทที่ 3}
การติดตั้งเฟิร์มแวร์บนบอร์ด Wio Terminal ต้องการไลบรารีเฉพาะทางด้านการจัดการจอแสดงผลและระบบไฟล์ การแยกโครงสร้างโค้ดออกเป็นเอนจินอิสระช่วยให้การบำรุงรักษาและการขยายขีดความสามารถทำได้ง่าย การคอมไพล์ผ่าน Arduino CLI ให้ความรวดเร็วและใช้หน่วยความจำแฟลชเพียงร้อยละ 20 ของความจุชิป ทำให้มีพื้นที่เหลือเฟือสำหรับการพัฒนาต่อยอด

\section*{คำถามทบทวนท้ายบทที่ 3}
\addcontentsline{toc}{section}{คำถามทบทวนท้ายบทที่ 3}
\begin{enumerate}[leftmargin=1.5em, itemsep=3pt]
    \item เหตุใดการใช้ไลบรารี TFT\_eSPI ทั่วไปจึงทำให้บอร์ด Wio Terminal เกิดอาการจอขาวค้าง และมีความแตกต่างจาก Seeed\_Arduino\_LCD อย่างไร
    \item คุณสมบัติ Smooth Font ในไฟล์ User\_Setup.h มีบทบาทอย่างไรในการเรนเดอร์ฟอนต์ภาษาไทยบนจอ LCD
    \item การออกแบบโค้ดแบบ Zero-Allocation ในเอนจิน TinyML ส่งผลดีอย่างไรต่อความเสถียรของระบบในระยะยาว
    \item จงอธิบายขั้นตอนการนำบอร์ด Wio Terminal เข้าสู่โหมด Bootloader เมื่อคอมพิวเตอร์ตรวจไม่พบพอร์ต Serial
\end{enumerate}
