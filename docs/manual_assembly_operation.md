## 1. บทนำและหลักการฟิสิกส์เชิงแสง

การตรวจวัดปริมาณธาตุอาหารหลักในดิน (ไนโตรเจน N, ฟอสฟอรัส P, และโพแทสเซียม K) รวมถึงการประเมินสมบัติเชิงแสงและกายภาพของของเหลวทางการเกษตร (เช่น น้ำหมักชีวภาพ น้ำชลประทาน สารละลายธาตุอาหารพืช) มีความจำเป็นอย่างยิ่งต่อการทำเกษตรแม่นยำ (Precision Agriculture)

ระบบสเปกโทรโฟโตมิเตอร์ NPK Level Meter 1.02 อาศัยหลักการทางทัศนศาสตร์ฟิสิกส์ตาม **กฎของเบียร์และแลมเบิร์ต (Beer-Lambert Law)**

$$A(\lambda) = -\log_{10}\left(\frac{I(\lambda) - I_{	ext{dark}}}{I_0(\lambda) - I_{	ext{dark}}}
ight) = \varepsilon(\lambda) \cdot b \cdot C$$

โดยที่
- $A(\lambda)$ คือ ค่าการดูดกลืนแสง (Absorbance) ณ ความยาวคลื่น $\lambda$
- $I_0(\lambda)$ คือ ความเข้มแสงเริ่มต้นที่ส่องผ่านสารละลายแบลงก์ (Blank Reference)
- $I(\lambda)$ คือ ความเข้มแสงที่ทะลุผ่านสารละลายตัวอย่าง (Sample Intensity)
- $I_{	ext{dark}}$ คือ สัญญาณกระแสมืดของเซนเซอร์ขณะดับไฟ (Dark Current)
- $b$ คือ ความยาวทางเดินแสงในคิวเวตต์ ($1.0	ext{ cm}$)
- $C$ คือ ความเข้มข้นของสารละลาย ($	ext{mg/kg}$)

### การเลือกความยาวคลื่นในการวิเคราะห์
1. **แสงสีน้ำเงิน ($\lambda \approx 465	ext{ nm}$):** ตรวจวัด ไนโตรเจน (N) สารละลายสีส้มอมน้ำตาล
2. **แสงสีฟ้าอมเขียว ($\lambda \approx 500	ext{ nm}$):** ตรวจวัดสารสีอินทรีย์และการดูดกลืนแสงช่วงสเปกตรัมกลาง
3. **แสงสีเขียว ($\lambda \approx 525	ext{ nm}$):** ตรวจวัด ฟอสฟอรัส (P) สารประกอบเชิงซ้อนสีน้ำเงินโมลิบดีนัม
4. **แสงสีเหลือง ($\lambda \approx 590	ext{ nm}$):** ตรวจวัดอนุภาคแขวนลอยและค่าความขุ่น
5. **แสงสีแดง ($\lambda \approx 625	ext{ nm}$):** ตรวจวัด โพแทสเซียม (K) ตะกอนแขวนลอยเตตระฟีนิลบอเรต

### ระบบเปลี่ยนความยาวคลื่นแสงอัตโนมัติ (Auto-Wavelength Switching Engine)
เพื่อป้องกันข้อผิดพลาดในการเปิดแสงผิดสีของผู้ปฏิบัติงาน เฟิร์มแวร์จะเปลี่ยนแหล่งกำเนิดแสง LED ตามฟังก์ชันการตรวจวัดทันทีที่เปลี่ยนหน้าจอ:
- **หน้า 2 (Nitrogen):** เปิดไฟสีน้ำเงิน (465 nm) ดูดกลืนสูงสุดกับสารสกัดไนเตรต/แอมโมเนีย
- **หน้า 3 (Phosphorus):** เปิดไฟสีแดง (625 nm) ดูดกลืนสูงสุดกับสารเชิงซ้อนฟอสโฟโมลิบดีนัมบลู
- **หน้า 4 (Potassium):** เปิดไฟสีแดง (625 nm) วัดการลดทอนความเข้มแสงและการกระเจิงจากตะกอนเตตระฟีนิลบอเรต
- **หน้า 5 (Soil pH):** เปิดไฟคู่เขียว/แดง (525/625 nm) วิเคราะห์อัตราส่วนสีสีย้อมอินดิเคเตอร์

### การสั่งงานด้วยปุ่มกดและจอยสติ๊ก
- **จอยสติ๊กโยกซ้าย / ขวา (`WIO_5S_LEFT / RIGHT`):** เลื่อนสลับหน้าจอวนลูป 8 หน้าจอ
- **จอยสติ๊กโยกขึ้น (`WIO_5S_UP`):** หน้า Dashboard / NPK / System Info: สลับโหมดคำนวณ `[AI TinyML]` $\to$ `[PL Poly]` $\to$ `[SC StdCurv]`
- **จอยสติ๊กโยกลง (`WIO_5S_DOWN`):**
  - หน้า Calibrate: สั่งบันทึกจุดสารมาตรฐาน (Step Calib)
  - หน้า NPK / pH: สั่งอ่านค่าและบันทึกข้อมูลด่วน
- **จอยสติ๊กกดตรงกลาง (`WIO_5S_PRESS`):**
  - หน้า Calibrate: บันทึกค่าศูนย์เทียบน้ำกลั่น (Zero Blank Reference)
  - หน้าอื่น: สลับเปิด/ปิด ไฟแสงสีขาว (White LED) ตรวจสอบตัวอย่าง
- **ปุ่ม A, B, C (ด้านบนตัวเครื่อง):**
  - หน้า Calibrate: เลือกธาตุที่ต้องการเทียบมาตรฐาน (C=ไนโตรเจน 465nm, B=ฟอสฟอรัส 525nm, A=โพแทสเซียม 625nm)
  - หน้า NPK: สลับเปิด/ปิด หลอดไฟแมนนวล (C=น้ำเงิน, B=เขียว, A=แดง)

## 5. ทฤษฎีและแบบจำลองการคำนวณเคมีวิเคราะห์

### 5.1 แบบจำลอง TinyML Deep Neural Network
โครงข่ายประสาทเทียม Multi-Layer Perceptron ($6 	o 12 	o 8 	o 3$) พร้อมระบบชดเชยความขุ่น:
- เวกเตอร์คุณลักษณะนำเข้า 6 ตัว: $b_p, g_p, r_p, c_{	ext{ratio}}, 	ext{lux}_{	ext{norm}}, A_{	ext{est}}$
- คำนวณแบบ C++ Zero-Allocation ไม่ใช้หน่วยความจำฮีป
- ความเร็วการประมวลผล $12.4\ \mu	ext{s}$ ต่อการวัด

### 5.2 แบบจำลองพหุนามสากล (Classical Polynomial)
$$N \,(	ext{mg/kg}) = -185.42 + 8.234\,b_p - 0.0412\,b_p^2 + 0.000091\,b_p^3$$
$$P \,(	ext{mg/kg}) = -224.18 + 12.56\,g_p - 0.0823\,g_p^2$$
$$K \,(	ext{mg/kg}) = -18.92 + 1.842\,r_p + 0.0156\,r_p^2$$

### 5.3 แบบจำลองเส้นตรงมาตรฐานสด (In-Situ Standard Curve)
$$C_{	ext{sample}} = \max\left(0.0, \, \frac{A_{	ext{sample}} - c}{m}
ight)$$

## 6. ขั้นตอนการปฏิบัติการตรวจวัดธาตุอาหารในดิน (NPK Soil Testing)

1. **การเตรียมตัวอย่างดิน:** ชั่งตัวอย่างดินแห้ง 5 กรัม ผสมน้ำยาสกัดธาตุอาหาร เขย่าเป็นเวลา 5 นาที แล้วตั้งทิ้งไว้ให้ตกตะกอน หรือกรองผ่านกระดาษกรอง Whatman No. 42
2. **การทำปฏิกิริยาสี:** ดูดสารละลายใส 2 มิลลิลิตร ใส่ลงในหลอดทดลอง เติมน้ำยาทดสอบเฉพาะของ N, P หรือ K ตามคู่มือสารเคมี
3. **การเทียบศูนย์แบลงก์ (Blanking):** รินน้ำกลั่นหรือสารละลายสกัดเปล่าใส่หลอดคิวเวตต์ ใส่ลงในช่องวัด ปิดฝากันแสง แล้วกดปุ่มจอยสติ๊กตรงกลาง (`WIO_5S_PRESS`) ในหน้า Calibrate เพื่อตั้งค่าศูนย์
4. **การวัดตัวอย่าง:** นำหลอดคิวเวตต์บรรจุสารตัวอย่างใส่ลงในช่องวัด ปิดฝากันแสง หน้าจอ NPK Level Meter จะแสดงค่าความเข้มข้นของ N, P, K แบบเรียลไทม์ และบันทึกลงในไฟล์ `NPK.csv` บน microSD Card ทุกวินาที

## 7. ขั้นตอนการปฏิบัติการตรวจวัดสมบัติของเหลวและสเปกตรัมแสง (Liquid Optics & Spectral Metrology)

1. เลื่อนจอยสติ๊กไปที่หน้าจอที่ 6 หรือ 7 (**Page 6: Matrix / Page 7: 5-Band Spectral Scan `[7/8]`**)
2. บรรจุน้ำกลั่นบริสุทธิ์ลงในหลอดคิวเวตต์ ใส่ลงในช่องวัด ปิดฝากันแสง แล้วกด **จอยสติ๊กตรงกลาง (`WIO_5S_PRESS`)** ในหน้า Calibrate เพื่อตั้งค่าอ้างอิง Zero Blanking ($I_0$) ทุกช่องคลื่น ($n=1.3330, \rho=0.9982\text{ g/cm}^3$)
3. เทน้ำกลั่นออก ซับหลอดคิวเวตต์ให้แห้ง แล้วบรรจุตัวอย่างของเหลวที่ต้องการตรวจวัด (เช่น น้ำชลประทาน น้ำหมักชีวภาพ สารละลายธาตุอาหารพืช)
4. กด **จอยสติ๊กโยกลง (`WIO_5S_DOWN`)** ในหน้า `[7/8]` เพื่อสั่งรันระบบกวาดสเปกตรัมหลายช่วงคลื่น (Auto-Wavelength Sweep 465–625 nm)
5. เครื่องจะประมวลผลและแสดงผลการวิเคราะห์บนหน้าจอทันที:
   - **ดัชนีหักเหของแสง ($n$):** คำนวณจากทัศนศาสตร์ฟิสิกส์ความละเอียดทศนิยม 4 ตำแหน่ง
   - **ความหนาแน่นของของเหลว ($\rho$):** ในหน่วย $\text{g/cm}^3$
   - **ความเข้มข้นสารละลายและน้ำตาล ($^\circ\text{Bx}$):** ในหน่วย Brix Degree ตามเกณฑ์ ICUMSA
   - **ระดับความขุ่น (Clarity):** จำแนกเป็น `CLEAR`, `SLIGHT TURBID`, หรือ `TURBID`
   - **สเปกตรัมการดูดกลืนแสง:** กราฟแท่งและตัวเลข Absorbance รายช่องคลื่น $465, 500, 525, 590, 625\text{ nm}$
6. ข้อมูลจะถูกบันทึกต่อท้ายไฟล์ `SPECTRUM.csv` และ `LIQUID_LOG.csv` บน microSD Card โดยอัตโนมัติ

## 8. การเทียบมาตรฐานและการสร้างเส้นโค้งมาตรฐาน (In-Situ Standard Curve Wizard)

1. เลื่อนจอยสติ๊กไปที่หน้าจอที่ 8 (**Page 8: Multi-Point Calibration Wizard `[8/8]`**)
2. เลือกธาตุอาหารที่ต้องการเทียบมาตรฐานผ่านปุ่มลัดด้านบน:
   - **กดปุ่ม C (ซ้าย):** ไนโตรเจน (N - สลับไฟ Blue LED 465 nm อัตโนมัติ)
   - **กดปุ่ม B (กลาง):** ฟอสฟอรัส (P - สลับไฟ Red LED 625 nm สำหรับ Molybdenum Blue อัตโนมัติ)
   - **กดปุ่ม A (ขวา):** โพแทสเซียม (K - สลับไฟ Red LED 625 nm สำหรับ Turbidimetry อัตโนมัติ)
3. **เทียบศูนย์แบลงก์:** ใส่หลอดน้ำกลั่นบริสุทธิ์ ปิดฝากันแสง แล้วกด **จอยสติ๊กตรงกลาง (`WIO_5S_PRESS`)**
4. **วัดจุดมาตรฐาน 5 จุดความเข้มข้น:**
   - ใส่สารละลายมาตรฐานความเข้มข้น $0\text{ mg/kg}$ แล้วกด **จอยสติ๊กโยกลง (`WIO_5S_DOWN`)**
   - เปลี่ยนสารละลายมาตรฐานเป็นความเข้มข้น $20, 40, 80, 160\text{ mg/kg}$ ตามลำดับ แล้วกดโยกลงทีละจุดจนครบ 5 จุด
5. **การคำนวณและประเมินผล:**
   - ระบบคำนวณการถดถอยเชิงเส้นตรง OLS (Ordinary Least Squares) บนฮาร์ดแวร์ ARM Cortex-M4F FPU อัตโนมัติ
   - พล็อตกราฟเส้นโค้งมาตรฐานและจุดพิกัดสารละลายสดบนหน้าจอ LCD
   - รายงานค่าสัมประสิทธิ์การตัดสินใจ $R^2$, ความชัน $m$, จุดตัดแกน $c$, ขีดจำกัดตรวจวัด LOD, และขีดจำกัดตรวจหาปริมาณ LOQ ตามมาตรฐาน IUPAC/ISO 17025
   - บันทึกพารามิเตอร์ลงหน่วยความจำถาวรและบันทึกประวัติลงไฟล์ `CALIB_LOG.csv` บน microSD Card ทันที

## 11. การเชื่อมต่อเครือข่าย Wi-Fi และสถาปัตยกรรม JSON REST Server

เครื่องสเปกโทรโฟโตมิเตอร์ Wio Terminal ติดตั้งโมดูลเครือข่ายไร้สาย Realtek RTL8720DN ที่รองรับการทำงานสองย่านความถี่ (2.4 GHz / 5.0 GHz) โดยเฟิร์มแวร์บรรจุเซิร์ฟเวอร์ HTTP REST API ขนาดเล็ก (Micro-Web-Server) บนพอร์ต 80 เพื่อให้บริการแลกเปลี่ยนข้อมูลในรูปแบบมาตรฐาน JSON

### 11.1 โหมดการทำงานของ Wi-Fi
1. **Station Mode (STA):** บอร์ดจะทำการเชื่อมต่อกับ Wi-Fi Router หรือ Mobile Hotspot อัตโนมัติ โดยระบุชื่อ SSID และรหัสผ่านใน `WiFi_Server_Engine.h`
2. **SoftAP Mode (Fallback):** หากอยู่นอกพื้นที่เครือข่ายหรือไม่สามารถเชื่อมต่อได้ บอร์ดจะสลับไปปล่อยสัญญาณ Access Point ชื่อ `NPK-Spectrometer-AP` (IP: `192.168.4.1`) โดยอัตโนมัติ

### 11.2 รายการชุดคำสั่ง REST API (JSON Protocol)
- `GET /api/status` ตรวจสอบสถานะการทำงาน แรงดันไฟฟ้า เซนเซอร์ และค่า RSSI
- `GET /api/latest` ดึงผลการวัดล่าสุด (N, P, K, $n$, $\rho$, Brix, Transmittance, Absorbance 5 ช่องคลื่น)
- `GET /api/history` สตรีมประวัติข้อมูลทั้งหมดในไฟล์ `DATA_LOG.json` จากการ์ด microSD
- `POST /api/scan-soil` สั่งให้เครื่องทำการสแกนดินแบบไร้สาย
- `POST /api/scan-liquid` สั่งให้เครื่องทำการสแกนของเหลวแบบไร้สาย
- `POST /api/calibrate` สั่งเทียบศูนย์แบลงก์ (Blank Calibration)

## 12. ระบบเว็บแอปพลิเคชันแดชบอร์ดและฐานข้อมูล JSON (Web Dashboard)

เพื่อความสะดวกในการปฏิบัติงานภาคสนามและในห้องปฏิบัติการ ได้จัดทำ Web Dashboard แบบ Responsive Glassmorphic หน้าตาสวยงามระดับพรีเมียมในโฟลเดอร์ `web/`

### 12.1 การเปิดใช้งานเว็บแอปพลิเคชัน
ผู้ใช้งานสามารถเปิดใช้งานแดชบอร์ดได้ทันทีผ่าน 2 ช่องทาง:
1. **เปิดผ่าน Local HTTP Server:**
   ```bash
   python3 -m http.server 5555 --directory web
   ```
   แล้วเข้าใช้งานผ่านเว็บเบราว์เซอร์ที่ `http://localhost:5555`
2. **เปิดไฟล์ `web/index.html`:** สามารถเปิดผ่านเบราว์เซอร์โดยตรง หรือนำขึ้น GitHub Pages

### 12.2 ฟังก์ชันเด่นของระบบแดชบอร์ด
- **Live Telemetry & Gauges:** แสดงค่า N, P, K และสมบัติของเหลว ($n$, $\rho$, Brix, Clarity) แบบเรียลไทม์
- **Dynamic 5-Wavelength Absorbance Chart:** กราฟิกสเปกตรัมแสง 5 ช่วงคลื่นพร้อมเส้นโค้ง Bézier นุ่มนวลและหมุดแสดงค่าการดูดกลืนแสง
- **Interactive JSON Database Manager:**
  - ตารางแสดงประวัติข้อมูลการวัดทั้งหมด พร้อมระบบค้นหา (Search) และตัวกรองประเภท
  - ปุ่ม **{ } JSON** เพื่อดูโครงสร้างข้อมูลดิบแบบละเอียด
  - ปุ่ม **ส่งออก JSON (Export JSON)** ดาวน์โหลดฐานข้อมูลเป็นไฟล์ `.json`
  - ปุ่ม **นำเข้า JSON (Import JSON)** โหลดฐานข้อมูลเดิมกลับเข้ามาวิเคราะห์
  - ปุ่ม **ส่งออก CSV (Export CSV)** เพื่อนำไปเปิดใน Microsoft Excel หรือโปรแกรมทางสถิติ
- **Mock Demo Mode:** มีโหมดจำลองออฟไลน์ในตัว ทำให้สามารถทดสอบฟังก์ชันการทำงาน กราฟิก และฐานข้อมูลได้ทันทีแม้อยู่นอกห้องปฏิบัติการ
