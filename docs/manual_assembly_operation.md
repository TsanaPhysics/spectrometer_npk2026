### 1 บทนำและหลักการฟิสิกส์เชิงแสง

การตรวจวัดปริมาณธาตุอาหารหลักในดินอันประกอบด้วยไนโตรเจน ฟอสฟอรัส และโพแทสเซียม (NPK) มีความสำคัญอย่างยิ่งต่อการบริหารจัดการปุ๋ยในการเกษตรแม่นยำ เครื่องมือนี้พัฒนาขึ้นโดยประยุกต์ใช้หลักการวัดการดูดกลืนและการสะท้อนแสงเชิงสเปกตรัม (Optical Spectroscopy) ร่วมกับเซนเซอร์สีความละเอียดสูงและการประมวลผลสัญญาณดิจิทัลบนบอร์ด Seeed Studio Wio Terminal

#### 1.1 กฎของเบียร์และแลมเบิร์ต (Beer-Lambert Law)
ความสัมพันธ์ระหว่างความเข้มแสงที่ทะลุผ่านสารละลายตัวอย่างกับความเข้มข้นของธาตุอาหารเป็นไปตามสมการ

$$A = -\log_{10}\left(\frac{I}{I_0}\right) = \varepsilon b C$$

โดยที่
- $A$ แทน ค่าการดูดกลืนแสง (Absorbance)
- $I_0$ แทน ความเข้มแสงเริ่มต้นจากแหล่งกำเนิดแสง
- $I$ แทน ความเข้มแสงที่ทะลุผ่านสารละลายตัวอย่าง
- $\varepsilon$ แทน สัมประสิทธิ์การดูดกลืนแสงโมลาร์
- $b$ แทน ความยาวทางเดินแสงในคิวเวตต์ (1.0 cm)
- $C$ แทน ความเข้มข้นของธาตุอาหารในดิน หน่วยมิลลิกรัมต่อกิโลกรัม (mg/kg)

#### 1.2 การจำแนกความยาวคลื่นแสงสำหรับธาตุอาหาร NPK
- **แสงสีน้ำเงิน (Blue ~465 nm):** ใช้ตรวจวัดธาตุไนโตรเจน (Nitrogen หรือ N) จากปฏิกิริยาเกิดสีส้มอมน้ำตาล
- **แสงสีเขียว (Green ~525 nm):** ใช้ตรวจวัดธาตุฟอสฟอรัส (Phosphorus หรือ P) จากปฏิกิริยาสารประกอบเชิงซ้อนสีน้ำเงินโมลิบดีนัม
- **แสงสีแดง (Red ~625 nm):** ใช้ตรวจวัดธาตุโพแทสเซียม (Potassium หรือ K) จากความขุ่นและการกระเจิงแสงของตะกอนเตตระฟีนิลบอเรต
- **แสงสีขาว (White 400-700 nm):** เกิดจากการผสมสีแดง เขียว และน้ำเงินพร้อมกัน ใช้สำหรับการเทียบมาตรฐานศูนย์ (Blank Calibration)

#### 2.3 ขั้นตอนการประกอบชิ้นส่วน
1. ยึดแท่นหลอดคิวเวตต์ (Cuvette Holder) เข้ากับฐานล่างของกล่องพิมพ์สามมิติ
2. ติดตั้งโมดูล Grove RGB LED ที่ผนังด้านข้างของช่องคิวเวตต์ ให้หน้าหลอดแนบสนิทกับหน้าต่างส่องแสง
3. ติดตั้งโมดูลเซนเซอร์ TCS34725 ตรงข้ามกับหลอด LED ในแนวแกนแสงเดียวกัน
4. ต่อสาย Grove 4-Pin จากหลอด LED เข้าพอร์ต Grove ด้านซ้าย (D0)
5. ต่อสาย Grove 4-Pin จากเซนเซอร์ TCS34725 เข้าพอร์ต Grove ด้านขวา (I2C)
6. ประกอบบอร์ด Wio Terminal เข้ากับฝาครอบด้านหน้า ขันสกรูให้แน่นหนา

### 4 คู่มือการปฏิบัติการและแบบจำลองการเทียบมาตรฐาน

#### 4.1 การควบคุมแสงสเปกตรัม
- **กดปุ่ม A:** สลับ เปิด/ปิด แสงสีแดง (Red LED)
- **กดปุ่ม B:** สลับ เปิด/ปิด แสงสีเขียว (Green LED)
- **กดปุ่ม C:** สลับ เปิด/ปิด แสงสีน้ำเงิน (Blue LED)
- **กดปุ่มจอยสติ๊กลงตรงกลาง (5-Way Press):** สลับ เปิด/ปิด แสงสีขาว (White LED) ทันทีในคลิกเดียว

#### 4.2 แบบจำลองพหุนามการเทียบมาตรฐาน
ระบบคำนวณสัดส่วนความเข้มแสงสัมพัทธ์

$$r_p = \frac{R}{R+G+B} \times 100, \quad g_p = \frac{G}{R+G+B} \times 100, \quad b_p = \frac{B}{R+G+B} \times 100$$

และแปลงเป็นค่าความเข้มข้นธาตุอาหารดินด้วยสมการพหุนาม

$$N \,(\text{mg/kg}) = -185.42 + 8.234\,b_p - 0.0412\,b_p^2 + 0.000091\,b_p^3$$
$$P \,(\text{mg/kg}) = -224.18 + 12.56\,g_p - 0.0823\,g_p^2$$
$$K \,(\text{mg/kg}) = -18.92 + 1.842\,r_p + 0.0156\,r_p^2$$

## 5. สถาปัตยกรรม TinyML / Edge AI Deep Learning ในเฟิร์มแวร์

เพื่อเพิ่มขีดความสามารถในการวิเคราะห์ตัวอย่างดินจริงที่มีความขุ่นและมีสารรบกวนในสารละลายสกัด ระบบเฟิร์มแวร์ได้รับการพัฒนาให้รองรับการประมวลผลด้วยโมเดลการเรียนรู้เชิงลึก (Deep Learning) แบบ Multi-Layer Perceptron (MLP) โดยตรงบนชิป ATSAMD51 ARM Cortex-M4F

### โครงสร้างเวกเตอร์คุณลักษณะนำเข้า (6 Input Features)
1. **$b_p$:** สัดส่วนเปอร์เซ็นต์แสงสีน้ำเงิน (Blue Percentage)
2. **$g_p$:** สัดส่วนเปอร์เซ็นต์แสงสีเขียว (Green Percentage)
3. **$r_p$:** สัดส่วนเปอร์เซ็นต์แสงสีแดง (Red Percentage)
4. **$c_{\text{ratio}}$:** อัตราส่วนช่องสัญญาณ Clear ($C / (R+G+B)$) สำหรับประเมินความขุ่นของสารละลาย
5. **$\text{lux}_{\text{norm}}$:** ค่าความสว่างรวมสัมพัทธ์ ($\text{Lux} / 1000$)
6. **$A_{\text{est}}$:** ค่าการดูดกลืนแสงสัมพัทธ์โดยประมาณตามกฎของเบียร์-แลมเบิร์ต ($-\log_{10}(I/I_0)$)

### การทำงานของ C++ Zero-Allocation Inference Engine
โมเดล TinyML ถูกแปลงค่าพารามิเตอร์ (Weights และ Biases) เป็นโค้ดภาษา C++ ที่มีฟังก์ชันคำนวณแบบ inlined ในไฟล์ `TinyML_Model.h`:
- สถาปัตยกรรม: $6 \to 12 \to 8 \to 3$
- ฟังก์ชันกระตุ้น: ReLU ($\max(0, x)$) สำหรับ Hidden Layers
- การใช้ประโยชน์จาก FPU: คำนวณแบบ 32-bit Single Precision Floating Point ด้วย Hardware FPU
- ไม่มีการจัดสรรฮีปแบบไดนามิก (Zero Heap Allocation) จึงไม่มีปัญหาหน่วยความจำรั่วไหล (No Memory Leak)
- ความเร็วในการประมวลผล: ประมาณ $12.4\ \mu\text{s}$ ต่อการวัด 1 ครั้ง

### การสลับโหมดการทำงานบนหน้าจอ LCD
ผู้ใช้งานสามารถกดโยกจอยสติ๊ก 5 ทิศทางขึ้นด้านบน (`WIO_5S_UP`) เพื่อสลับโหมดระหว่าง:
- **`[AI]` (ป้ายสีเขียว):** พยากรณ์ค่า N, P, K ด้วยโครงข่ายประสาทเทียม TinyML Edge AI พร้อมระบบชดเชยความขุ่น
- **`[PL]` (ป้ายสีเหลือง):** คำนวณค่า N, P, K ด้วยแบบจำลองสมการพหุนามดั้งเดิม (Classical Polynomial Regression)

## 6. ระบบหลายหน้าจอและการสแกนสเปกตรัมการดูดกลืนแสง (Phase 1)

### โครงสร้าง 4 หน้าจอ (Carousel Pages)
ผู้ใช้งานสามารถใช้ **จอยสติ๊ก 5 ทิศทาง โยกซ้าย (`WIO_5S_LEFT`) หรือ โยกขวา (`WIO_5S_RIGHT`)** เพื่อเปลี่ยนหน้าจอ:
1. **Page 1: System Dashboard** ตรวจสอบสถานะฮาร์ดแวร์ ชิป SAMD51 FPU แฟลช แรม เซนเซอร์แสง และการ์ด SD
2. **Page 2: NPK Level Meter 1.02** หน้าจอตรวจวัดความเข้มข้น N, P, K แบบเรียลไทม์ พร้อมป้ายแสดงสถานะโหมด `[AI]` หรือ `[PL]` และการควบคุมเปิด-ปิดไฟ LED รายสี
3. **Page 3: Absorbance Spectrum Plot** กราฟิก 2D แสดงเส้นโค้งการดูดกลืนแสง $A(\lambda)$ ช่วง 400 - 700 nm แบบเรียลไทม์
   - โยกจอยสติ๊กลง (`WIO_5S_DOWN`) เพื่อสั่ง **Auto-Scan**
   - ระบบจะดับไฟวัด Dark Current ($I_{\text{dark}}$) แล้วกวาดแสง 5 ช่วงคลื่น (Blue, Cyan, Green, Yellow, Red)
   - คำนวณ Absorbance และพล็อตกราฟเส้นพร้อมจุดมาร์กเกอร์และค่าพีค $\lambda_{\max}, A_{\max}$
   - หาก $A_{\max} > 1.50$ หน้าจอจะแจ้งเตือน `! WARN: HIGH ABS - DILUTE 1:5 !`
   - ข้อมูลสเปกตรัมจะถูกบันทึกลงในไฟล์ `SPECTRUM.csv` บน microSD Card โดยอัตโนมัติ
4. **Page 4: Calibration & Blank Wizard**
   - แสดงตารางค่า Blank Reference ($I_0$) และ Dark Current ($I_{\text{dark}}$)
   - นำหลอดคิวเวตต์บรรจุน้ำกลั่นใส่ลงในช่องวัด แล้วโยกจอยสติ๊กลง (`WIO_5S_DOWN`) เพื่อบันทึกค่า Blank Reference ใหม่ลงในหน่วยความจำและไฟล์ `BLANK.DAT` บน microSD Card

## 7. ระบบเทียบมาตรฐานสร้างเส้นโค้งมาตรฐานในตัวเครื่อง (Phase 2 Calibration Wizard)

### การทำงานของระบบ Standard Curve Engine
เฟิร์มแวร์เวอร์ชัน Phase 2 มาพร้อมระบบคำนวณการถดถอยเชิงเส้นตรง (Ordinary Least Squares: OLS) บนชิป ATSAMD51 โดยตรง เพื่อแปลงค่าการดูดกลืนแสงเป็นความเข้มข้นธาตุอาหารจริงในดิน:
- คำนวณสมการความสัมพันธ์: $A = m \cdot C + c$
- สัมประสิทธิ์การตัดสินใจ ($R^2$) เพื่อยืนยันความเป็นเส้นตรงของสารมาตรฐาน
- ขีดจำกัดการตรวจวัด (Limit of Detection: $\text{LOD} = 3.3 \cdot s_{y/x} / m$)
- ขีดจำกัดการหาปริมาณ (Limit of Quantification: $\text{LOQ} = 10.0 \cdot s_{y/x} / m$)

### ขั้นตอนการเทียบมาตรฐานในหน้าจอ Page 4:
1. กด **จอยสติ๊กโยกขวา** ไปยังหน้าจอที่ 4 (**Calibration Curve & Metrology**)
2. เลือกธาตุอาหารที่ต้องการเทียบมาตรฐาน:
   - **ปุ่ม C:** ไนโตรเจน (N) สเปกตรัมสีน้ำเงิน 465 nm
   - **ปุ่ม B:** ฟอสฟอรัส (P) สเปกตรัมสีเขียว 525 nm
   - **ปุ่ม A:** โพแทสเซียม (K) สเปกตรัมสีแดง 625 nm
3. ใส่สารละลายมาตรฐานความเข้มข้น $0, 20, 40, 80, 160\text{ mg/kg}$ ตามลำดับ แล้วกด **จอยสติ๊กโยกลง (`WIO_5S_DOWN`)** ทีละจุด
4. ระบบจะคำนวณสมการเส้นตรงและวาดกราฟิกเส้นตรงมาตรฐานพร้อมจุดมาร์กเกอร์และแผงสถิติ $R^2, \text{LOD}, \text{LOQ}$ บนหน้าจอ LCD ทันที
5. ข้อมูลการคาลิเบรตจะถูกบันทึกลงในไฟล์ `CALIB_CURVE.DAT` และ `CALIB_LOG.csv` บน microSD Card

### การเลือกใช้งาน 3 โหมดวิเคราะห์ในหน้าจอ NPK Meter:
ในหน้าจอที่ 2 ผู้ใช้งานสามารถกด **จอยสติ๊กโยกขึ้น (`WIO_5S_UP`)** เพื่อสลับโหมด:
- **`[AI]` (สีเขียว):** พยากรณ์ด้วยโครงข่ายประสาทเทียม TinyML Deep Learning
- **`[PL]` (สีเหลือง):** คำนวณด้วยสมการพหุนามสากล (Classical Polynomial)
- **`[SC]` (สีฟ้า):** คำนวณด้วยสมการเส้นโค้งมาตรฐานที่เทียบสดในแปลง ($C = (A - c) / m$)
