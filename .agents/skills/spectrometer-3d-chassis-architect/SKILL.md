# Spectrometer 3D Chassis Architect (SpectorV4 Master Standard)

กรอบมาตรฐานวิศวกรรม 3 มิติและการออกแบบโครงสร้างกล่องบรรจุอุปกรณ์สเปกโทรโฟโตมิเตอร์ตรวจวัดธาตุอาหารดิน (NPK) และสมบัติของเหลวทางการเกษตร ถอดรหัสโครงสร้างเชิงลึกจากไฟล์ต้นแบบหลัก **`models_3d/SpectorV4.stl`** ผสานเข้ากับหลักการทางทัศนศาสตร์ฟิสิกส์ (Optical Physics) กฎของเบียร์และแลมเบิร์ต (Beer-Lambert Law) และมาตรฐานการวิจัยของ **ผู้ช่วยศาสตราจารย์ ดร.ชีวะ ทัศนา** (หน่วยวิจัยเกษตรดิจิทัล JC_AI_SciRBRU คณะวิทยาศาสตร์และเทคโนโลยี มหาวิทยาลัยราชภัฏรำไพพรรณี)

---

## 1. การถอดรหัสเรขาคณิตและดีเอ็นเอการออกแบบของ SpectorV4 (Reverse-Engineering DNA)

จากการวิเคราะห์โครงสร้างตาข่าย 3 มิติ (Mesh Topology) ของไฟล์ `SpectorV4.stl` (ขนาด 13,120 Triangles รูปทรงสมบูรณ์แบบ 100% Manifold ไร้รอยรั่วขอบ Mesh Boundary):

```
                        ┌──────────────────────────────────────┐
                        │      Wio Terminal Console Deck       │ (หน้าเอียง Ergonomic Display)
                        │      LCD 2.4" + 3 Buttons + Joystick │
                        └──────────────────┬───────────────────┘
                                           │
 ┌─────────────────────────────────────────▼────────────────────────────────────────┐
 │               Dual-Compartment Precision Optical Rig (SpectorV4)                 │
 │                                                                                  │
 │  [WS2812B NeoPixel] ──► [Ø3mm Aperture] ──► [Cuvette 10mm] ──► [Adafruit TCS34725]│
 │  (Light Guide Input)         (แนวแกนแสงตรง Coaxial Centerline)     (Detector Output)│
 └─────────────────────────────────────────┬────────────────────────────────────────┘
                                           │
                        ┌──────────────────▼───────────────────┐
                        │     Integrated Base & Cable Relief   │ (ร่องสาย Grove & แท่นรองแล็บ)
                        └──────────────────────────────────────┘
```

### 1.1 ขนาดมิติภายนอกหลัก (Master Bounding Envelope)
* **ความกว้างรวมแกน X ($\Delta X$):** $95.00\text{ mm}$ (ขอบเขต $-63.00\text{ mm}$ ถึง $+32.00\text{ mm}$)
* **ความลึกรวมแกน Y ($\Delta Y$):** $122.00\text{ mm}$ (ขอบเขต $-52.00\text{ mm}$ ถึง $+70.00\text{ mm}$)
* **ความสูงรวมแกน Z ($\Delta Z$):** $82.00\text{ mm}$ (ขอบเขต $0.00\text{ mm}$ ถึง $+82.00\text{ mm}$)
* **น้ำหนักเชิงโครงสร้าง (Volume Ratio):** ออกแบบเป็นกล่องแบบผสม Desktop Workstation และ Handheld Field Rig วางตั้งโต๊ะได้อย่างมั่นคง ปราศจากการสั่นไหวระหว่างการอ่านค่าสเปกตรัม

### 1.2 การแบ่งพื้นที่ใช้สอยภายใน (Zonal Architecture)
1. **โซนคอนโซลด้านหน้าและจอแสดงผล (Front Console Zone $Y \in [-52, -10]\text{ mm}$):**
   * พื้นที่รับหน้าจอ Wio Terminal และอินเทอร์เฟซผู้ใช้
   * ระดับความสูงลาดเอียงเพื่อมุมมองการอ่านค่า LCD 2.4 นิ้วที่ดีที่สุด ($Z = 58\text{ mm}$ ถึง $82\text{ mm}$)
   * ช่องเจาะสำหรับปุ่มกดด้านบน A, B, C และจอยสติ๊ก 5 ทิศทาง
2. **โซนห้องตรวจวัดทางทัศนศาสตร์ (Optical Core Chamber $X \in [-38, -13]\text{ mm}, Y \in [-31, -11]\text{ mm}$):**
   * ช่องใส่หลอดคิวเวตต์มาตรฐาน $10\text{ mm}$ ($12.75 \times 12.75\text{ mm}$)
   * แนวแกนแสงโคแอกเชียล (Coaxial Beam Tunnel) วางตัวในแนวขวางตัดผ่านกึ่งกลางคิวเวตต์ที่ความสูง $15.0\text{ mm}$ เหนือก้นหลอด
   * ช่องจำกัดลำแสงคู่ (Collimating Apertures) ขนาด $\varnothing 3.0\text{ mm}$ ป้องกันแสงกระเจิง
3. **โซนฐานและช่องร้อยสายสัญญาณ (Base Flange & Cable Tunnels $Z \in [0, 28]\text{ mm}$):**
   * ช่องทางเดินสาย Grove 4-Pin แยกอิสระระหว่างพอร์ตซ้าย (หลอด LED WS2812B) และพอร์ตขวา (เซนเซอร์ I2C TCS34725)
   * ฐานรากมีจุดยึดสกรูและร่องรองรับแบตเตอรี่สำรองสำหรับการใช้งานภาคสนาม

## 2. กฎเหล็กวิศวกรรมทัศนศาสตร์สำหรับสเปกโทรโฟโตมิเตอร์ (Optical Rig Design Laws)

ในการออกแบบโครงสร้าง 3D สำหรับอุปกรณ์สเปกตรัม ต้องปฏิบัติตามกฎ 5 ข้ออย่างเคร่งครัด:

### กฎข้อที่ 1: แนวแกนแสงต้องตรงกันสมบูรณ์ (Coaxial Collinear Alignment)
* แหล่งกำเนิดแสง (WS2812B), รูจำกัดลำแสงเข้า (Input Aperture), ผิวด้านรับแสงของคิวเวตต์, สารละลายตัวอย่าง, ผิวด้านส่งผ่านแสง, รูจำกัดลำแสงออก (Output Aperture), และตัวตรวจจับโฟโตไดโอด (TCS34725) ต้องอยู่ในแนวแกนเชิงแสงเดียวกัน $\pm 0.05\text{ mm}$
* ความสูงระดับแกนแสง ($Z_{\text{opt}}$) ต้องอยู่ที่ **$15.0\text{ mm}$** จากก้นหลอดคิวเวตต์เสมอ เพื่อให้อยู่กึ่งกลางปริมาตรของเหลวมาตรฐาน $2.0 - 3.5\text{ mL}$

### กฎข้อที่ 2: ช่องจำกัดลำแสงต้องตัดแสงกระเจิง (Dual Collimation Apertures)
* ขนาดรูรับแสงต้องมีเส้นผ่านศูนย์กลาง **$3.0\text{ mm}$** ความยาวอุโมงค์อย่างน้อย **$3.0 - 3.5\text{ mm}$**
* รูทางเข้าทำหน้าที่ตัดแสงรอบข้างให้เหลือเฉพาะลำแสงขนานที่ตั้งฉากกับผนังคิวเวตต์ ลดการสะท้อนเฟรernel (Fresnel Reflection)
* รูทางออกทำหน้าที่เป็น Stray-Light Baffle กรองตัดแสงกระเจิงจากอนุภาคดินแขวนลอยในสารละลายสกัด

### กฎข้อที่ 3: ระบบฝาครอบกันแสงแบบเขี้ยวซ้อนเขาวงกต (Double-Stepped Labyrinth Seal)
* ห้ามใช้ฝาครอบแบบสวมผิวเรียบชั้นเดียว (Single Flat Lip) เด็ดขาด เนื่องจากแสงแวดล้อมสามารถเล็ดลอดผ่านรอยต่อได้
* ต้องใช้ระบบขั้นบันได 2 ชั้น (Double-stepped Baffle / Labyrinth Joint) บังคับให้ลำแสงภายนอกต้องสะท้อนหักมุม 90 องศาอย่างน้อย 2 ครั้ง ทำให้พลังงานแสงลดลงจนเป็นศูนย์ก่อนเข้าสู่ห้องวัด

### กฎข้อที่ 4: ระยะเผื่อการสวมหลอดคิวเวตต์ (Cuvette Well Clearance)
* หลอดคิวเวตต์มาตรฐานมีขนาด $12.50 \times 12.50\text{ mm}$
* ขนาดช่องเสียบในโมเดล 3D ต้องกำหนดที่ **$12.75 \times 12.75\text{ mm}$** (ระยะเผื่อ Tolerance $+0.25\text{ mm}$ รวมสองฝั่ง หรือข้างละ $0.125\text{ mm}$)
* มุมปากช่องคิวเวตต์ต้องมี Chamfer ลบมุมลาดเอียง $45^\circ$ ลึก $1.5\text{ mm}$ เพื่อความสะดวกในการใส่หลอด

### กฎข้อที่ 5: ความทึบแสงของผนังชิ้นงาน (Light Opacity Threshold)
* ผนังห้องวัดแสงรอบทิศทางต้องมีความหนาเนื้อพลาสติกไม่น้อยกว่า **$3.0 - 3.5\text{ mm}$**
* ต้องพิมพ์ด้วย Infill **100% Solid** เพื่อป้องกันปรากฏการณ์ Light Bleeding ผ่านโครงตาข่าย Infill ภายใน

## 3. รูปแบบโค้ดพารามิเตอร์ OpenSCAD มาตรฐาน

เมื่อต้องสร้างหรือปรับปรุงโมเดล 3D สเปกโตรมิเตอร์ ให้ใช้โครงสร้าง OpenSCAD แบบโมดูลาร์ดังนี้:

```openscad
// =============================================================================
// NPK Spectrometer Optical Engine - Parametric OpenSCAD Template
// =============================================================================
$fn = 60; // Smooth curves

// --- Parameters ---
tolerance          = 0.25;  // 3D printer clearance (mm)
cuvette_size       = 12.50; // Standard 10mm pathlength cuvette
cuvette_slot       = cuvette_size + tolerance; // 12.75 mm
cuvette_floor_th   = 3.00;  // Floor base
optical_z_height   = 15.00; // Optical axis from cuvette floor
optical_axis_z     = cuvette_floor_th + optical_z_height; // 18.00 mm
aperture_dia       = 3.00;  // Collimating tunnel diameter

module optical_core(w=46, d=30, h=36) {
    difference() {
        // Main block
        translate([-w/2, -d/2, 0]) cube([w, d, h]);
        
        // Cuvette slot
        translate([-cuvette_slot/2, -cuvette_slot/2, cuvette_floor_th])
            cube([cuvette_slot, cuvette_slot, h + 10]);
            
        // Coaxial aperture tunnel through X axis
        translate([-w/2 - 1, 0, optical_axis_z])
            rotate([0, 90, 0]) cylinder(d=aperture_dia, h=w + 2);
            
        // Sensor mounting pockets (Left: LED, Right: TCS34725)
        translate([-w/2 - 0.1, -10.5, optical_axis_z - 10.5]) cube([3.2, 21, 21]);
        translate([ w/2 - 3.1, -10.5, optical_axis_z - 10.5]) cube([3.2, 21, 21]);
    }
}
```

## 4. ไปป์ไลน์การคำนวณและส่งออกเมช STL ด้วย Python (SDF & Marching Cubes)

สำหรับการสร้างไฟล์ `.STL` ที่สมบูรณ์แบบโดยไม่ต้องพึ่งพาโปรแกรม CAD ภายนอก ให้ใช้แนวทาง Signed Distance Functions (SDF) และอัลกอริทึม Marching Cubes ใน `scripts/generate_3d_models.py`:

1. กำหนดฟังก์ชันคณิตศาสตร์ระยะทางของทรงเรขาคณิตพื้นฐาน:
   * `sdf_box(X, Y, Z, bx, by, bz, ...)` สำหรับตัวกล่องและเบ้าเซนเซอร์
   * `sdf_cylinder_x(X, Y, Z, r, l, ...)` สำหรับอุโมงค์ทางเดินแสง
   * `sdf_cylinder_z(X, Y, Z, r, h, ...)` สำหรับรูสกรูยึด M2.5 / M3
2. ทำการรวมเนื้อ (Union: $\min$) และลบโพรง (Difference: $\max(A, -B)$)
3. รัน `skimage.measure.marching_cubes` ที่ความละเอียด $0.25 - 0.30\text{ mm}$
4. ส่งออกไฟล์ Binary STL ที่มี Header 80 ไบต์ และ Normal Vectors คำนวณเสร็จสมบูรณ์

## 5. มาตรฐานการตั้งค่า Slicer สำหรับพิมพ์ 3 มิติ (Research-Grade DFM)

เพื่อให้ชิ้นงานพิมพ์มีคุณสมบัติตรงตามเกณฑ์เคมีวิเคราะห์:

| พารามิเตอร์ | ค่าที่แนะนำ | เหตุผลทางเทคนิค |
| :--- | :--- | :--- |
| **วัสดุเส้นใย** | **PLA+ หรือ PETG สีดำด้าน (Matte Black)** | ลดการสะท้อนแสงภายในห้องวัด (Diffuse Absorption) |
| **Infill Density** | **100% Solid** | ป้องกันแสงรั่วทะลุผ่านช่องว่างภายในเนื้อพลาสติก |
| **Wall Perimeters** | **4 ถึง 5 Loops** (หนา $\ge 2.0\text{ mm}$) | เพิ่มความแข็งแรงและป้องกันแสงแวดล้อมทะลุผ่าน |
| **Layer Height** | **0.16 – 0.20 mm** | ผิวสัมผัสเรียบเนียน ไม่ติดขัดการสวมหลอดคิวเวตต์ |
| **Support** | **ไม่ต้องเปิด Support** | เรขาคณิตออกแบบมุมลาดเอียง $45^\circ$ Self-Supporting |
| **Orientation** | วางหน้าแปลนฐานติดแท่นพิมพ์ | ให้แนวแกนแสงขนานกับระนาบพิมพ์ XY เพื่อความกลมมนของรูรับแสง |

## 6. เช็กลิสต์การตรวจประเมินก่อนนำไปประกอบใช้งานจริง (Quality Assurance Checklist)

* [ ] ตรวจสอบว่าหลอดคิวเวตต์ $12.5\text{ mm}$ สามารถสไลด์ลงในช่องได้ราบรื่น ไม่ฝืดและไม่โยกคลอน
* [ ] ส่องไฟฉายความเข้มสูง (LED Torch) จากภายนอกกล่องขณะปิดฝา Labyrinth Lid แล้วอ่านค่าดิบ TCS34725 ($I_{\text{dark}}$) ค่าต้องไม่เพิ่มขึ้นเกิน $0.5\%$
* [ ] ลำแสงจาก WS2812B ส่องผ่านรูรับแสงเข้าสู่กึ่งกลางหลอดคิวเวตต์ในแนวตั้งฉากสมบูรณ์
* [ ] สาย Grove เสียบเข้ากับบอร์ด Wio Terminal ได้แน่นหนาและมีช่องร้อยสาย ไม่ถูกบีบอัด
