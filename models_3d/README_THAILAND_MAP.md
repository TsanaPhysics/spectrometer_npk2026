# แบบจำลอง 3 มิติแผนที่ภูมิประเทศประเทศไทย (Kingdom of Thailand 3D Topographic Model)
### หน่วยวิจัยฟิสิกส์เกษตรดิจิทัลและปัญญาประดิษฐ์ (JC_AI_SciRBRU)
**สาขาวิชาฟิสิกส์ คณะวิทยาศาสตร์และเทคโนโลยี มหาวิทยาลัยราชภัฏรำไพพรรณี**

## 1. ภาพรวมงานออกแบบและวิศวกรรมภูมิสารสนเทศ (GIS & Engineering Overview)

แบบจำลอง 3 มิติแผนที่ประเทศไทยชุดนี้ ได้รับการออกแบบและพัฒนาขึ้นโดยใช้ข้อมูล **แบบจำลองระดับสูงเชิงเลขจริง (Real-World Digital Elevation Model - DEM)** จากดาวเทียม ร่วมกับข้อมูลพิกัดขอบเขตการปกครอง **77 จังหวัด** ของประเทศไทย โดยมีคุณลักษณะเด่นดังนี้:

1. **ระดับความสูงภูมิประเทศจริง (Topographic Relief):**
   - ถอดรหัสโครงสร้างเทือกเขาหลักของประเทศ: ทิวเขาถนนธงชัย, ทิวเขาแดนลาว, ทิวเขาหลวงพระบาง, ทิวเขาเพชรบูรณ์, ทิวเขาดงพญาเย็น, ทิวเขาบรรทัด/จันทบุรี (เขาสอยดาว, เขาคิชฌกูฏ), ทิวเขาตะนาวศรี และทิวเขาสันกาลาคีรีในภาคใต้
   - ความสูงยอดเขาสำคัญถูกต้องตามหลักธรณีวิทยา: **ดอยอินทนนท์ ($2,565\text{ m}$)**, **ดอยหลวงเชียงดาว ($2,175\text{ m}$)**, **เขาค้อ ($1,820\text{ m}$)**, **ยอดเขาหลวง นครศรีฯ ($1,835\text{ m}$)** และ **เขาสอยดาว จันทบุรี ($1,675\text{ m}$)**
2. **ขอบเขต 77 จังหวัดสลักร่องลึกคมชัด (Engraved Provincial Boundaries):**
   - แนวเส้นขอบเขตจังหวัดทั้ง 77 จังหวัด สลักร่องลึก **$0.40\text{ mm}$** ลงบนผิวภูมิประเทศอย่างประณีต ช่วยให้มองเห็นและสัมผัสตำแหน่งของแต่ละจังหวัดได้อย่างชัดเจน
3. **แป้นจารึกวิชาการมาตรฐาน (Integrated Display Plinth):**
   - แป้นฐานพิมพ์ขนาดมาตรฐาน **$120 \times 200\text{ mm}$** ขอบตัดเฉียง (Chamfered Bevel)
   - สลักอักษรนูน (Embossed Typography) ภาษาไทยและภาษาอังกฤษ:
     - ด้านบน: **"ราชอาณาจักรไทย • THAILAND"** และ **"TOPOGRAPHIC RELIEF MAP 2026"**
     - ด้านล่าง: **"หน่วยวิจัยเกษตรดิจิทัล JC_AI_SciRBRU • มรภ.รำไพพรรณี"** และมาตราส่วน **SCALE 1:10,000,000**
     - เข็มทิศบอกทิศเหนือ (Compass Rose $\uparrow$ N) และแถบมาตราส่วนระยะทาง ($0 - 100 - 200\text{ km}$)
     - ขีดพิกัดละติจูด-ลองจิจูด ($98^\circ\text{E} - 104^\circ\text{E}$, $8^\circ\text{N} - 20^\circ\text{N}$)

## 3. คำแนะนำการพิมพ์ 3 มิติ (3D Printing & Slicer Guide)

โมเดลได้รับการออกแบบให้เป็น **Watertight Solid 100% (ไร้ขอบเปิด ไร้ข้อผิดพลาด Non-manifold)** สามารถนำเข้าโปรแกรม Slicer (Bambu Studio, PrusaSlicer, OrcaSlicer, Cura) แล้วพิมพ์ได้ทันทีโดยไม่ต้องซ่อมเมช

* **ขนาดชิ้นงาน:**
  - แป้นจารึก: $120.0 \times 200.0 \times 12.4\text{ mm}$ (เหมาะกับแท่นพิมพ์มาตรฐานขนาด $180 \times 180\text{ mm}$ ขึ้นไป)
  - หุ่นลอยตัว: $73.7 \times 134.9 \times 12.5\text{ mm}$ (พิมพ์ได้บนเครื่องพิมพ์ทุกรุ่น)
* **ความละเอียดชั้นพิมพ์ (Layer Height):**
  - แนะนำ **$0.16\text{ mm}$** หรือ **$0.20\text{ mm}$**
* **Infill:**
  - แนะนำ **15% - 20% ลาย Gyroid** หรือ Grid
* **โครงสร้างค้ำยัน (Supports):**
  - **ไม่ต้องเปิด Support (No Support Needed)** ฐานด้านล่างเรียบสนิทแนบแท่นพิมพ์ $100\%$

### เคล็ดลับการพิมพ์แบบสลับสีเส้นใยตามระดับความสูง (Color Change by Layer):
สำหรับผู้ใช้เครื่องพิมพ์ 3D ทั่วไปที่ไม่มีหัวพิมพ์หลายสี (Single Extruder) สามารถตั้งค่าการหยุดเปลี่ยนสีเส้นใย (Pause / Filament Change) ใน Slicer ตามระดับความสูง $Z$ เพื่อให้ได้แผนที่สีสันธรรมชาติสวยงาม:
1. **$Z = 0.0 - 2.0\text{ mm}$:** เส้นใย **สีน้ำเงินเข้ม (Deep Blue)** — ฐานทะเลอ่าวไทยและทะเลอันดามัน
2. **$Z = 2.0 - 3.2\text{ mm}$:** เส้นใย **สีฟ้าคราม (Cyan / Light Blue)** — แนวไหล่ทวีปและชายฝั่ง
3. **$Z = 3.2 - 6.0\text{ mm}$:** เส้นใย **สีเขียวสด (Lush Green)** — ที่ราบลุ่มภาคกลาง ลุ่มน้ำเจ้าพระยา และที่ราบชายฝั่ง
4. **$Z = 6.0 - 9.0\text{ mm}$:** เส้นใย **สีเหลืองมัสตาร์ด / สีส้มอ่อน (Yellow / Ochre)** — ที่ราบสูงโคราชและเนินเขาสูง
5. **$Z = 9.0 - 11.5\text{ mm}$:** เส้นใย **สีน้ำตาล / ดินเผา (Terracotta / Brown)** — แนวสันเขาสูงภาคเหนือและภาคใต้
6. **$Z > 11.5\text{ mm}$:** เส้นใย **สีขาวบริสุทธิ์ (Pure White)** — ยอดดอยสูงอินทนนท์ เชียงดาว

## 4. วิธีเปิดใช้งานโปรแกรมจำลอง 3 มิติบนเว็บเบราว์เซอร์

เปิดไฟล์ `models_3d/thailand_viewer_3d.html` หรือ `web/thailand_viewer_3d.html` ด้วย Google Chrome, Safari, หรือ Edge เพื่อ:
- คลิกเมาส์ซ้ายลากเพื่อหมุนชมรอบทิศทาง $360^\circ$
- เลื่อนลูกกลิ้งเมาส์เพื่อซูมเข้าดูรายละเอียดเทือกเขาและร่องรอยต่อแต่ละจังหวัด
- กดปุ่มสลับระหว่าง **"แป้นจารึก (Plinth)"** และ **"หุ่นลอยตัว (Standalone)"**
- ปรับแถบเลื่อน **"ความสูงภูมิประเทศ (Relief Exaggeration)"** จาก $0.5\times$ ถึง $2.5\times$
- สลับธีมวัสดุ: **ภูมิประเทศจริง (Hypsometric Gradient)**, **ดำด้าน (Matte)**, **ทองบรอนซ์ (Royal Gold)**, หรือ **หยกเกษตร (Jade)**
- กดปุ่ม **"📍 หมุดสำคัญ"** เพื่อดูตำแหน่งยอดดอยอินทนนท์, กรุงเทพฯ, มรภ.รำไพพรรณี จันทบุรี, เขาค้อ, ยอดเขาหลวง ฯลฯ
- กดปุ่ม **"📥 ดาวน์โหลดไฟล์ STL พร้อมพิมพ์ 3D"** เพื่อรับไฟล์ไปพิมพ์ใช้งานได้ทันที
