# แบบจำลอง 3 มิติแผนที่ภูมิประเทศและโครงข่ายลุ่มน้ำประเทศไทย (Kingdom of Thailand 3D Topographic & River Basin Model)
### หน่วยวิจัยฟิสิกส์เกษตรดิจิทัลและปัญญาประดิษฐ์ (JC_AI_SciRBRU)
**สาขาวิชาฟิสิกส์ คณะวิทยาศาสตร์และเทคโนโลยี มหาวิทยาลัยราชภัฏรำไพพรรณี**

## 1. ภาพรวมงานออกแบบและวิศวกรรมภูมิสารสนเทศ (GIS & Engineering Overview)

แบบจำลอง 3 มิติแผนที่ประเทศไทยชุดนี้ ได้รับการออกแบบและพัฒนาขึ้นโดยใช้ข้อมูล **แบบจำลองระดับสูงเชิงเลขจริง (Real-World Digital Elevation Model - DEM)** จากดาวเทียม ร่วมกับข้อมูลพิกัดขอบเขตการปกครอง **77 จังหวัด** และข้อมูล **โครงข่ายลุ่มแม่น้ำสายหลัก 37 สาย** ของประเทศไทย โดยมีคุณลักษณะเด่นดังนี้:

1. **ระดับความสูงภูมิประเทศจริง (Topographic Relief):**
   - ถอดรหัสโครงสร้างเทือกเขาหลักของประเทศ: ทิวเขาถนนธงชัย, ทิวเขาแดนลาว, ทิวเขาหลวงพระบาง, ทิวเขาเพชรบูรณ์, ทิวเขาดงพญาเย็น, ทิวเขาบรรทัด/จันทบุรี (เขาสอยดาว, เขาคิชฌกูฏ), ทิวเขาตะนาวศรี และทิวเขาสันกาลาคีรีในภาคใต้
   - ความสูงยอดเขาสำคัญถูกต้องตามหลักธรณีวิทยา: **ดอยอินทนนท์ (2,565 m)**, **ดอยหลวงเชียงดาว (2,175 m)**, **เขาค้อ (1,820 m)**, **ยอดเขาหลวง นครศรีฯ (1,835 m)** และ **เขาสอยดาว จันทบุรี (1,675 m)**
2. **ร่องน้ำลุ่มแม่น้ำหลักสลักลึกคมชัด (Carved River Channels & Drainage Basins):**
   - สลักร่องแม่น้ำลึก **-0.42 mm** (ความกว้างลำน้ำ 0.90 - 1.35 mm) ลงบนผิวโมเดล 3D จริง ครอบคลุม 5 ลุ่มน้ำหลัก:
     - **ลุ่มน้ำเจ้าพระยา:** แม่น้ำปิง, วัง, ยม, น่าน, เจ้าพระยา, ป่าสัก, ท่าจีน
     - **ลุ่มน้ำแม่กลอง:** แม่น้ำแม่กลอง, แควใหญ่, แควน้อย
     - **ลุ่มน้ำชี-มูล และแม่น้ำโขง:** แม่น้ำชี, แม่น้ำมูล, แม่น้ำสงคราม, แนวแม่น้ำโขง
     - **ลุ่มน้ำบางปะกงและชายฝั่งตะวันออก:** แม่น้ำบางปะกง, แม่น้ำนครนายก, แม่น้ำปราจีนบุรี, แม่น้ำจันทบุรี
     - **ลุ่มน้ำภาคใต้:** แม่น้ำตาปี, แม่น้ำพุมดวง, แม่น้ำปัตตานี, ทะเลสาบสงขลา
3. **ขอบเขต 77 จังหวัดสลักร่องลึกคมชัด (Engraved Provincial Boundaries):**
   - แนวเส้นขอบเขตจังหวัดทั้ง 77 จังหวัด สลักร่องลึก **0.40 mm** ลงบนผิวภูมิประเทศอย่างประณีต ช่วยให้มองเห็นและสัมผัสตำแหน่งของแต่ละจังหวัดได้อย่างชัดเจน
4. **แป้นจารึกวิชาการมาตรฐาน (Integrated Display Plinth):**
   - แป้นฐานพิมพ์ขนาดมาตรฐาน **120 x 200 mm** ขอบตัดเฉียง (Chamfered Bevel)
   - สลักอักษรนูน (Embossed Typography) ภาษาไทยและภาษาอังกฤษ:
     - ด้านบน: **"ราชอาณาจักรไทย • THAILAND"** และ **"TOPOGRAPHIC RELIEF MAP 2026"**
     - ด้านล่าง: **"หน่วยวิจัยเกษตรดิจิทัล JC_AI_SciRBRU • มรภ.รำไพพรรณี"** และมาตราส่วน **SCALE 1:10,000,000**
     - เข็มทิศบอกทิศเหนือ (Compass Rose ↑ N) และแถบมาตราส่วนระยะทาง (0 - 100 - 200 km)
     - ขีดพิกัดละติจูด-ลองจิจูด (98°E - 104°E, 8°N - 20°N)

## 3. ระบบสกรีนระดับชั้นความสูงและโทนสี (Hypsometric Screening & Color Grading)

ในระบบแสดงผล 3 มิติและแบบจำลอง ได้จัดทำระบบ **สกรีนระดับความสูงเชิงวิทยาศาสตร์ (Hypsometric Elevation Screening)** แบ่งเป็น 7 ระดับชัดเจน:

| ระดับความสูง | สภาพภูมิประเทศ | โทนสีมาตรฐาน (HEX) | พื้นที่สำคัญในประเทศไทย |
| :--- | :--- | :--- | :--- |
| **ระดับน้ำทะเล (0 m)** | อ่าวไทยและทะเลอันดามัน | `#081c3b` (Deep Ocean) | แนวชายฝั่งทะเลรอบประเทศ |
| **< 100 m** | ดินดอนปากแม่น้ำและที่ราบชายฝั่ง | `#1b4332` (Lush Alluvial) | ที่ราบลุ่มน้ำเจ้าพระยาตอนล่าง กรุงเทพฯ สมุทรปราการ |
| **100 - 300 m** | ที่ราบลุ่มน้ำตอนบนและแอ่งที่ราบ | `#2d6a4f` (Plains Green) | ที่ราบลุ่มน้ำปิง-ยม-น่าน แอ่งลุ่มน้ำชี-มูล ภาคอีสาน |
| **300 - 600 m** | ที่ราบสูงและลอนคลื่นเนินเขา | `#e9c46a` (Khorat Sandstone) | ที่ราบสูงโคราช เขาใหญ่ ลอนคลื่นภาคตะวันออก |
| **600 - 1,000 m** | เชิงเขาและเนินเขาสูง | `#f4a261` (Submontane Amber) | เชิงเทือกเขาเพชรบูรณ์ สันปันน้ำ ดงพญาเย็น |
| **1,000 - 1,500 m** | เทือกเขาระดับกลาง | `#e76f51` (Terracotta Ridge) | เทือกเขาถนนธงชัย เทือกเขาดอยสุเทพ ทิวเขาบรรทัด จันทบุรี |
| **1,500 - 2,000 m** | สันเขาสูงและยอดดอย | `#b0413e` (High Mountain Sienna) | ดอยหลวงเชียงดาว เขาค้อ ยอดเขาหลวง นครศรีฯ |
| **> 2,000 m** | ยอดเขาสูงชันแกรนิตอัลไพน์ | `#ffffff` (Alpine Summit Snow) | ยอดดอยอินทนนท์ (2,565 m) ยอดเขาสูงสุดของไทย |

## 4. คำแนะนำการพิมพ์ 3 มิติ (3D Printing & Slicer Guide)

โมเดลได้รับการออกแบบให้เป็น **Watertight Solid 100% (ไร้ขอบเปิด ไร้ข้อผิดพลาด Non-manifold)** สามารถนำเข้าโปรแกรม Slicer (Bambu Studio, PrusaSlicer, OrcaSlicer, Cura) แล้วพิมพ์ได้ทันทีโดยไม่ต้องซ่อมเมช

* **ขนาดชิ้นงาน:**
  - แป้นจารึก: 120.0 x 200.0 x 12.4 mm (เหมาะกับแท่นพิมพ์มาตรฐานขนาด 180 x 180 mm ขึ้นไป)
  - หุ่นลอยตัว: 73.7 x 134.9 x 12.5 mm (พิมพ์ได้บนเครื่องพิมพ์ทุกรุ่น)
* **ความละเอียดชั้นพิมพ์ (Layer Height):**
  - แนะนำ **0.16 mm** หรือ **0.20 mm** (ช่วยให้ร่องแม่น้ำลึก -0.42 mm ปรากฏคมชัด 2-3 เลเยอร์)
* **Infill:**
  - แนะนำ **15% - 20% ลาย Gyroid** หรือ Grid
* **โครงสร้างค้ำยัน (Supports):**
  - **ไม่ต้องเปิด Support (No Support Needed)** ฐานด้านล่างเรียบสนิทแนบแท่นพิมพ์ 100%

### เคล็ดลับการพิมพ์แบบสลับสีเส้นใยตามระดับความสูง (Color Change by Layer):
สำหรับผู้ใช้เครื่องพิมพ์ 3D ทั่วไปที่ไม่มีหัวพิมพ์หลายสี (Single Extruder) สามารถตั้งค่าการหยุดเปลี่ยนสีเส้นใย (Pause / Filament Change) ใน Slicer ตามระดับความสูง Z เพื่อให้ได้แผนที่สีสันธรรมชาติสวยงาม:
1. **Z = 0.0 - 2.0 mm:** เส้นใย **สีน้ำเงินเข้ม (Deep Blue)** — ฐานทะเลอ่าวไทยและทะเลอันดามัน
2. **Z = 2.0 - 3.2 mm:** เส้นใย **สีฟ้าคราม (Cyan / Light Blue)** — แนวไหล่ทวีปและชายฝั่ง
3. **Z = 3.2 - 6.0 mm:** เส้นใย **สีเขียวสด (Lush Green)** — ที่ราบลุ่มภาคกลาง ลุ่มน้ำเจ้าพระยา และที่ราบชายฝั่ง
4. **Z = 6.0 - 9.0 mm:** เส้นใย **สีเหลืองมัสตาร์ด / สีส้มอ่อน (Yellow / Ochre)** — ที่ราบสูงโคราชและเนินเขาสูง
5. **Z = 9.0 - 11.5 mm:** เส้นใย **สีน้ำตาล / ดินเผา (Terracotta / Brown)** — แนวสันเขาสูงภาคเหนือและภาคใต้
6. **Z > 11.5 mm:** เส้นใย **สีขาวบริสุทธิ์ (Pure White)** — ยอดดอยสูงอินทนนท์ เชียงดาว

## 5. วิธีเปิดใช้งานโปรแกรมจำลอง 3 มิติบนเว็บเบราว์เซอร์

เปิดไฟล์ `models_3d/thailand_viewer_3d.html` หรือ `web/thailand_viewer_3d.html` ด้วย Google Chrome, Safari, หรือ Edge เพื่อ:
- คลิกเมาส์ซ้ายลากเพื่อหมุนชมรอบทิศทาง 360°
- เลื่อนลูกกลิ้งเมาส์เพื่อซูมเข้าดูรายละเอียดเทือกเขาและร่องรอยต่อแต่ละจังหวัดและร่องแม่น้ำ
- กดปุ่มสลับระหว่าง **"แป้นจารึก (Plinth)"** และ **"หุ่นลอยตัว (Standalone)"**
- ปรับแถบเลื่อน **"ขยายความสูงภูมิประเทศ (Relief Exaggeration)"** จาก 0.5x ถึง 2.5x
- สลับธีมสีและสกรีนชั้นความสูง:
  - **🌈 กายภาพแนชแนลจีโอ (Atlas Gradient):** เกรเดียนต์ความสูง 10 ระดับ นุ่มนวลสมจริง
  - **📊 สกรีนระดับชั้นความสูง (Stepped Screening):** ควอนไทซ์ระดับความสูง 7 ชั้นสี พร้อมตารางเลเจนด์
  - **🌊 โครงข่ายอุทกวิทยา (Hydrology Map):** เน้นลุ่มน้ำ ปากน้ำ และพื้นที่ระบายน้ำ
  - **🌿 หยกเกษตร (Agri-Jade), 🏆 ทองบรอนซ์ (Bronze), 🖤 ดำด้าน (Matte)**
- กดปุ่มเปิด-ปิด **"🌊 เส้นทางน้ำ 3D"** และเลือกกรองลุ่มน้ำเฉพาะ (เจ้าพระยา, ชี-มูล, แม่กลอง, ตะวันออก, ใต้)
- กดปุ่ม **"💧 ปากน้ำ & ชุมทาง"** เพื่อดูจุดบรรจบแม่น้ำสำคัญ (ปากน้ำโพ, ปากมูล, ปากน้ำเจ้าพระยา, ปากน้ำตาปี ฯลฯ)
- กดปุ่ม **"📍 หมุดยอดเขา"** เพื่อดูตำแหน่งยอดดอยอินทนนท์, กรุงเทพฯ, มรภ.รำไพพรรณี จันทบุรี, เขาค้อ, ยอดเขาหลวง ฯลฯ
- กดปุ่ม **"📥 ดาวน์โหลดโมเดล 3D STL (สลักร่องแม่น้ำ)"** เพื่อรับไฟล์ไปพิมพ์ใช้งานได้ทันที
