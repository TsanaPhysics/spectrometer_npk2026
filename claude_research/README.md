## การทำซ้ำผลลัพธ์

สคริปต์ใช้พาธสัมพัทธ์ รันจากที่ใดก็ได้

```bash
python3 scripts/reanalysis_phosphorus_q1.py     # เขียนทับ models/phosphorus_q1_revalidation.json
python3 scripts/make_figures_q1.py              # เขียนทับ figures/*.png
```

ต้องการ `numpy`, `scipy`, `pandas`, `matplotlib`

ทดสอบเฟิร์มแวร์บนเครื่องพัฒนา

```bash
gcc -O2 -Wall -Wextra -o /tmp/ptest ทดสอบ.c -lm   # เรียก phosphorus_selftest(0.30f) ต้องคืนค่า 0
```

## สิ่งที่ยังต้องเก็บข้อมูลเพิ่ม

รายการเหล่านี้ **ไม่ได้เติมตัวเลขให้** เพราะไม่มีข้อมูลจริงรองรับ

1. วัดซ้ำอย่างน้อย 3 ซ้ำต่อระดับความเข้มข้น
2. ทดลองชดเชยความขุ่น เปรียบเทียบตัวอย่างขุ่นกับตัวอย่างใส
3. ทดสอบการคืนกลับในสารสกัด Bray II จากดินจริง พร้อมตัวอย่างเปล่าคู่กัน
4. เทียบกับเครื่องสเปกโตรโฟโตมิเตอร์ตั้งโต๊ะที่ 880 nm
5. ผลของอุณหภูมิภาคสนาม 28–38 °C
6. บันทึกการวัดเวลาประมวลผลบนบอร์ดจริง
